# Stats Domain - CLAUDE.md

## Responsibility
Analyzing relationship data, calculating sync scores, and providing insights.

## Key Components
- `analytics_processor.dart`: Logic for parsing history into insights.
- `sync_score_model.dart`: Scoring algorithm for partner closeness.
- `insight_charts.dart`: Visual representation of trends.

## Guidelines
- Analysis should be non-intrusive.
- Use meaningful visualizations (not just raw numbers).
- Respect data privacy - provide options to clear history.
