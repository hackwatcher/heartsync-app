# Chat Domain - CLAUDE.md

## Responsibility
Shared messaging, emotional reactions, and media exchange between partners.

## Key Components
- `chat_screen.dart`: Main interaction point.
- `message_bubble.dart`: Themed message display.
- `reaction_service.dart`: Handling "Love", "Care", and "Miss you" reactions.

## Guidelines
- Messages should be stored locally for offline access.
- Support "Rich Feelings" (animated reactions).
- Ensure End-to-End Encryption where possible.
